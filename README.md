# NexusIntern — Online Internship Portal with Trainer Code Review & Approvals

A state-of-the-art React + Tailwind CSS web platform for online internships (1, 2, and 6-month durations) with solo & group tracks, interactive code review studio with trainer approval workflows, day-wise schedule, protected SOP viewing, and enterprise admin control center.

## ✨ Features
- **Flexible Internship Durations**: 1-month fast-track sprint, 2-month foundation, and 6-month enterprise mastery.
- **Individual & Group Sprints**: Solo assessment tracks and multi-developer collaborative team sprints with peer review checks.
- **Trainer Code Review Studio**: Side-by-side git diff inspection with trainer approvals, syntax highlighting, and inline line commenting.
- **Senior Trainer Hub**: Trainer availability badges, ratings, verified student testimonials, and direct LinkedIn profile links.
- **Enterprise Admin Command Center**: Tiered discount policy engine, DRM protected SOP day-wise schedule manager, trainer queue workload rebalancing, and multi-gateway payment adapters.
- **Theme & Design**: Ultra-premium UI with dark/light mode toggle, glassmorphic cards, vibrant gradient accents, and responsive layout.

## 🛠️ Tech Stack
- **Frontend**: React 19, Tailwind CSS v4, Lucide React icons
- **Build Tool**: Vite with Hot Module Replacement (HMR)

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
